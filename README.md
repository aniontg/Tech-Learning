# TECH & LEARNING 

**TECH & LEARNING** is an educational blog focused on exploring the relationship between technology, education, and the way students learn.

The featured article, **“How Technology Is Changing The Way Students Learn,”** explores how technology is transforming education through online learning, educational applications, digital resources, and artificial intelligence.

## About the Project

This project was created as a front-end web development project to practise building a structured and interactive educational blog.

The website uses semantic HTML elements to organise the page into a header, navigation, main content, article sections, video content, registration area, references, and footer.

## Features

* Responsive blog layout
* Navigation menu for:

  * Home
  * Technology
  * Education
  * Countries
  * About
* Featured article on technology and education
* Educational images with descriptive alternative text
* Sections covering:

  * Online Learning
  * Educational Apps and Digital Resources
  * Artificial Intelligence in Learning
* Embedded YouTube educational video
* Registration section for learning updates
* References and external educational resources
* Footer with author information
* Favicon and supporting project assets

The article also includes practical examples of educational platforms such as **Duolingo, Khan Academy, Quizlet, Google Classroom, and YouTube**.

##  Artificial Intelligence in Learning

The project examines how AI can support personalised learning, provide feedback, assist teachers, and help identify areas where students may need additional support.

It also considers concerns such as privacy and potential bias in AI systems, highlighting the importance of responsible use of AI in education.

##  Multimedia Content

The blog includes an embedded YouTube video as part of the learning content, providing visitors with an additional way to engage with the topic.

##  Registration Feature

The page includes a **“Register for Updates”** section where visitors can join the learning community and receive education updates.

The registration area is connected to a React root element and requires JavaScript to function.

##  Technologies Used

* **HTML5** — Used to structure the webpage and organise the blog content using semantic elements.
* **CSS3** — Used for styling and presentation through the external `technology.css` stylesheet.
* **JavaScript** — Used to add functionality to the webpage through the project's JavaScript file.
* **React** — Integrated into the page for the registration functionality using React and ReactDOM.
* **YouTube Embed** — Used to provide supporting video content.
